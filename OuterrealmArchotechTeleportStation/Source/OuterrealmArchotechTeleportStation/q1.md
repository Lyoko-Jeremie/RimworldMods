# RimWorld 1.6 原版女性标准人形头身拼接资料

本文基于 rimsage 查询到的 RimWorld 1.6 原版代码与 Def，目标是把“女性标准角色”的头和身体按游戏运行时的站立绘制方式拼接成一张参考图，交给画师绘制头发、衣服和身体附件。

## 结论摘要

如果只做一张最常用的成人女性正面参考图，建议使用：

- 身体：`Things/Pawn/Humanlike/Bodies/Naked_Female_south`
- 头：`Things/Pawn/Humanlike/Heads/Female/Female_Average_Normal_south`
- 头部中心相对身体中心偏移：`(x=0, z=+0.34)` 游戏格单位
- 身体和头默认网格尺寸：都是 `1.5 x 1.5` 游戏格单位
- 成人体型缩放：`bodySizeFactor = 1`，所以无需额外缩放

若用同尺寸贴图做拼接，例如头和身体 PNG 都是 `128 x 128`，则：

- 1 游戏格单位 = `128 / 1.5 = 85.333...` 像素
- 头中心向上移动 `0.34 * 85.333... = 29.01` 像素
- 在普通图片坐标中，Y 轴向下为正，所以头图层中心应放在身体中心上方约 `29 px`

通用像素公式：

```text
pixelsPerGameUnit = texturePixelSize / 1.5
headPixelOffsetX = gameOffsetX * pixelsPerGameUnit
headPixelOffsetY = -gameOffsetZ * pixelsPerGameUnit
```

正面/背面成人女性：`gameOffsetX = 0`，`gameOffsetZ = 0.34`。

东西侧成人女性：东向 `gameOffsetX = +0.10`，西向 `gameOffsetX = -0.10`，`gameOffsetZ = 0.34`。

## 贴图路径

### 女性身体 BodyTypeDef

原版 `BodyTypeDef Female`：

```xml
<defName>Female</defName>
<headOffset>(0.10, 0.34)</headOffset>
<bodyNakedGraphicPath>Things/Pawn/Humanlike/Bodies/Naked_Female</bodyNakedGraphicPath>
<bodyDessicatedGraphicPath>Things/Pawn/Humanlike/Bodies/Dessicated/Dessicated_Thin</bodyDessicatedGraphicPath>
<bodyGraphicScale>(1, 1)</bodyGraphicScale>
```

`Graphic_Multi` 会按方向加载后缀：

- `Things/Pawn/Humanlike/Bodies/Naked_Female_north`
- `Things/Pawn/Humanlike/Bodies/Naked_Female_east`
- `Things/Pawn/Humanlike/Bodies/Naked_Female_south`
- `Things/Pawn/Humanlike/Bodies/Naked_Female_west`

### 女性普通头 HeadTypeDef

原版普通可随机女性头型：

| HeadTypeDef | graphicPath | narrow | 备注 |
| --- | --- | --- | --- |
| `Female_AverageNormal` | `Things/Pawn/Humanlike/Heads/Female/Female_Average_Normal` | false | 建议作为标准参考 |
| `Female_AveragePointy` | `Things/Pawn/Humanlike/Heads/Female/Female_Average_Pointy` | false | 普通随机头 |
| `Female_AverageWide` | `Things/Pawn/Humanlike/Heads/Female/Female_Average_Wide` | false | 普通随机头 |
| `Female_NarrowNormal` | `Things/Pawn/Humanlike/Heads/Female/Female_Narrow_Normal` | true | 窄头 |
| `Female_NarrowPointy` | `Things/Pawn/Humanlike/Heads/Female/Female_Narrow_Pointy` | true | 窄头 |
| `Female_NarrowWide` | `Things/Pawn/Humanlike/Heads/Female/Female_Narrow_Wide` | true | 窄头 |

基因相关的女性重下颚头：

| HeadTypeDef | graphicPath | randomChosen | 备注 |
| --- | --- | --- | --- |
| `Female_HeavyJawNormal` | `Things/Pawn/Humanlike/Heads/Female/Female_HeavyJaw_Normal` | false | 需要 `Jaw_Heavy` 基因，不是普通随机标准头 |

每个头同样按方向加载：

- `{graphicPath}_north`
- `{graphicPath}_east`
- `{graphicPath}_south`
- `{graphicPath}_west`

如果某个方向贴图缺失，`Graphic_Multi` 会尝试用其他方向贴图回退；东西向缺失时可能复用另一侧并翻转 UV。

## 原版运行时绘制流程

### 人形渲染树

人类种族使用 `renderTree`：`Humanlike`。

核心节点顺序：

- `Body`
  - `nodeClass = PawnRenderNode_Body`
  - `workerClass = PawnRenderNodeWorker_Body`
  - `baseLayer = 0`，没有额外 `drawSize`
  - 使用肤色 shader，身体颜色来自皮肤色
- `Head`
  - `nodeClass = PawnRenderNode_Head`
  - `workerClass = PawnRenderNodeWorker_Head`
  - `baseLayer = 50`
  - 没有额外 `drawSize`
  - 头节点下再挂头部纹身、胡须、头发、头部服装、状态覆盖等

对静态站立成人角色来说，身体先画，头后画。头和身体共享同一个根矩阵，只是头节点多了 `BaseHeadOffsetAt(facing)`。

### 身体贴图选择

`PawnRenderNode_Body.GraphicFor` 对普通新鲜人形使用：

```csharp
GraphicDatabase.Get<Graphic_Multi>(
    pawn.story.bodyType.bodyNakedGraphicPath,
    shader,
    Vector2.one,
    this.ColorFor(pawn));
```

女性普通裸体身体就是：

```text
Things/Pawn/Humanlike/Bodies/Naked_Female
```

如果腐朽/干尸模式，则会改用：

```text
Things/Pawn/Humanlike/Bodies/Dessicated/Dessicated_Thin
```

### 头贴图选择

`PawnRenderNode_Head.GraphicFor` 对普通有头 pawn 使用：

```csharp
headType.GetGraphic(pawn, this.ColorFor(pawn))
```

`HeadTypeDef.GetGraphic` 内部使用：

```csharp
GraphicDatabase.Get<Graphic_Multi>(
    this.graphicPath,
    shader,
    Vector2.one,
    color);
```

所以头部贴图由 `pawn.story.headType.graphicPath` 决定。

## 核心偏移值

### Def 中的偏移

女性身体 Def 的头部偏移：

```xml
<headOffset>(0.10, 0.34)</headOffset>
```

这是 `Vector2`：

- `x = 0.10`：侧面朝向时的水平偏移
- `y = 0.34`：头相对身体中心向上的偏移，运行时转成 Unity/RimWorld 平面中的 `z`

### 运行时代码公式

`PawnRenderer.BaseHeadOffsetAt(Rot4 rotation)`：

```csharp
Vector2 vector2 = pawn.story.bodyType.headOffset
    * Mathf.Sqrt(pawn.ageTracker.CurLifeStage.bodySizeFactor);

switch (rotation.AsInt)
{
  case 0:
    return new Vector3(0.0f, 0.0f, vector2.y);
  case 1:
    return new Vector3(vector2.x, 0.0f, vector2.y);
  case 2:
    return new Vector3(0.0f, 0.0f, vector2.y);
  case 3:
    return new Vector3(-vector2.x, 0.0f, vector2.y);
}
```

方向对应：

| Rot4 | AsInt | 头中心偏移，成人女性 |
| --- | ---: | --- |
| North | 0 | `(0, 0, +0.34)` |
| East | 1 | `(+0.10, 0, +0.34)` |
| South | 2 | `(0, 0, +0.34)` |
| West | 3 | `(-0.10, 0, +0.34)` |

成人 `HumanlikeAdult` 的 `bodySizeFactor` 默认是 `1`，因此：

```text
sqrt(bodySizeFactor) = 1
最终偏移 = Female.headOffset
```

儿童、婴儿或其他 life stage 会使用 `sqrt(bodySizeFactor)` 缩放这个偏移。

## 网格尺寸与拼接坐标

### 成人人形默认网格

`HumanlikeMeshPoolUtility`：

- 身体宽度：成人默认 `1.5`
- 头部宽度：成人默认 `1.5`
- 身体网格：`1.5 x 1.5`
- 头部网格：`1.5 x 1.5`

`Female.bodyGraphicScale = (1,1)`，所以女性标准身体没有额外缩放。

### 游戏单位坐标

以站立正面 `South` 为例，设身体中心为 `(0,0)`，这里用图片平面坐标 `x/z` 表示：

```text
身体中心 = (0, 0)
身体网格范围 = x [-0.75, +0.75], z [-0.75, +0.75]

头中心 = (0, +0.34)
头网格范围 = x [-0.75, +0.75], z [-0.41, +1.09]
```

注意：网格范围不是实体轮廓范围，贴图四周大量透明像素会参与占位。画师拼图时应以 PNG 透明图层中心对齐，不要按可见像素外框重新裁切后再对齐，否则偏移会变。

### 像素坐标换算

如果身体和头图都保持原版同尺寸，例如常见 `128 x 128`：

```text
pixelsPerGameUnit = 128 / 1.5 = 85.333333
headOffsetZPixels = 0.34 * 85.333333 = 29.013333
headOffsetXPixels = 0.10 * 85.333333 = 8.533333
```

正面/背面：

```text
头中心 X = 身体中心 X
头中心 Y = 身体中心 Y - 29 px
```

东向：

```text
头中心 X = 身体中心 X + 8.5 px
头中心 Y = 身体中心 Y - 29 px
```

西向：

```text
头中心 X = 身体中心 X - 8.5 px
头中心 Y = 身体中心 Y - 29 px
```

如果贴图尺寸不是 `128`，把 `128` 替换成实际 PNG 宽度即可。前提是头和身体依然被映射到 `1.5 x 1.5` 的人形网格上。

## 头发、衣服和附件相关信息

### 头发

头发不是画在头贴图里，而是 `Head` 的子节点，在头之后按 `baseLayer = 62` 绘制。头发网格大小来自 `HeadTypeDef.hairMeshSize`：

| 头型 | hairMeshSize |
| --- | --- |
| Average 系列 | `(1.5, 1.5)` |
| Narrow 系列 | `(1.3, 1.5)` |
| HeavyJaw | `(1.5, 1.5)` |

所以如果画师要画头发参考，普通 Average 头发仍可按 `1.5 x 1.5` 头部网格处理；窄头头发宽度更窄，为 `1.3`。

### 服装

身体服装挂在身体节点的 `Apparel root`，`baseLayer = 20`。头部服装挂在头节点的 `Apparel root`，`baseLayer = 70`。

普通身体服装通常需要按照身体方向做 `_north/_east/_south/_west`。头部装备同理，但会受到头型、头发遮挡规则和 `renderSkipFlags` 影响。

### 身体附件

RimWorld 1.6 的人形渲染树支持通过 `PawnRenderNodeProperties` 和 `DrawData` 添加附件节点。若附件使用身体部位锚点，锚点来自 `BodyTypeDef.woundAnchors` 等数据；若只是给画师画整体参考，优先使用上面的头身中心偏移，不要直接拿伤口锚点当身体中心。

女性身体 Def 中部分可参考锚点：

| 朝向 | 部位/标签 | offset | 用途 |
| --- | --- | --- | --- |
| South | Torso | `(0,0,-0.06)` | 躯干区域 |
| South | LeftLeg | `(0.12,0,-0.34)` | 左腿 |
| South | RightLeg | `(-0.12,0,-0.34)` | 右腿 |
| South | LeftShoulder | `(0.12,0,0.01)` | 左肩 |
| South | RightShoulder | `(-0.12,0,0.01)` | 右肩 |
| South | FullHead | `(0,0,0)`，layer Head | 头部局部锚点 |
| South | LeftEye | `(0.095,0,0.18)`，layer Head | 左眼 |
| South | RightEye | `(-0.095,0,0.18)`，layer Head | 右眼 |
| West | Torso | `(0,0,-0.13)` | 侧面躯干 |
| West | FullHead | `(0,0,0)`，layer Head | 侧面头部 |

这些锚点主要用于伤口/眼睛/附着物定位，坐标语义和头身拼接中心偏移不同。

## 给画师的建议工作流

1. 保留原版 PNG 画布尺寸和透明边距，不要自动裁剪透明边。
2. 建一个合成画布，把 `Naked_Female_south` 身体图层放在中心。
3. 把 `Female_Average_Normal_south` 头图层放到同一中心点。
4. 将头图层向上移动约 `29 px`，如果原图不是 `128 x 128`，按 `0.34 * 宽度 / 1.5` 重算。
5. 画衣服、头发和附件时，身体类内容参考身体图层，头发/脸部附件参考头图层位置。
6. 如果要做东西向参考，头额外水平移动约 `8.5 px`，东向右移，西向左移。

## 512x512 画布的偏移计算

如果身体和头部贴图都绘制在 `512 x 512` 画布中，并且保持原版透明边距和中心点不变，则成人女性标准人形仍然映射到 `1.5 x 1.5` 游戏格单位。

计算每个游戏格单位对应的像素数：

```text
pixelsPerGameUnit = texturePixelSize / meshSize
pixelsPerGameUnit = 512 / 1.5
pixelsPerGameUnit = 341.333333...
```

正面/背面成人女性的头部偏移是：

```text
gameOffsetX = 0
gameOffsetZ = 0.34
```

换算为像素：

```text
headPixelOffsetX = 0 * 341.333333... = 0 px
headPixelOffsetY = -0.34 * 341.333333... = -116.053333... px
```

因此在普通图片坐标中，Y 轴向下为正：

```text
正面 South：头图层中心 = 身体图层中心 + (0 px, -116.05 px)
背面 North：头图层中心 = 身体图层中心 + (0 px, -116.05 px)
```

实际绘图可取整为：

```text
正面/背面：头图层中心向上移动 116 px
```

东西侧成人女性的头部偏移是：

```text
East gameOffsetX = +0.10
West gameOffsetX = -0.10
gameOffsetZ = 0.34
```

水平偏移换算：

```text
0.10 * 341.333333... = 34.133333... px
```

因此：

```text
东向 East：头图层中心 = 身体图层中心 + (+34.13 px, -116.05 px)
西向 West：头图层中心 = 身体图层中心 + (-34.13 px, -116.05 px)
```

实际绘图可取整为：

```text
东向：头图层中心向右移动 34 px，向上移动 116 px
西向：头图层中心向左移动 34 px，向上移动 116 px
```

## 统一绘制基准

如果不为不同头型分别设计不同大小的头发，建议以 `Female_AverageNormal` 作为标准参照头型。

原因：

- 它是普通女性随机头型之一，不依赖基因或特殊状态。
- `Average` 系列的 `hairMeshSize` 是默认标准值 `(1.5, 1.5)`。
- `Female_AverageNormal` 的贴图路径是 `Things/Pawn/Humanlike/Heads/Female/Female_Average_Normal`。
- `Narrow` 系列头型会把头发网格宽度改成 `(1.3, 1.5)`，不适合作为统一头发尺寸的基准。
- `Female_HeavyJawNormal` 需要 `Jaw_Heavy` 基因，且 `randomChosen=false`，也不适合作为通用标准。

因此头发统一基准为：

```text
Female_AverageNormal
Things/Pawn/Humanlike/Heads/Female/Female_Average_Normal
头发网格：1.5 x 1.5
```

如果不为不同身体类型分别设计衣服，建议以 `BodyTypeDef Female` 作为本项目女性标准身体的衣服参照。

原因：

- 用户目标是“原版游戏的女性标准角色”，对应原版女性身体 Def 是 `Female`。
- `Female.bodyNakedGraphicPath = Things/Pawn/Humanlike/Bodies/Naked_Female`。
- `Female.bodyGraphicScale = (1, 1)`，没有额外缩放，适合作为标准衣服底稿。
- 成人女性身体默认网格是 `1.5 x 1.5`，与普通成人头部网格一致，方便画师统一画布和中心点。
- 其他体型如 `Thin`、`Fat`、`Hulk`、`Male` 的身体轮廓不同，不适合作为女性标准衣服的唯一参照。

因此衣服统一基准为：

```text
BodyTypeDef Female
Things/Pawn/Humanlike/Bodies/Naked_Female
身体网格：1.5 x 1.5
bodyGraphicScale：1, 1
```

给画师的简化说明：

```text
头发按 Female_AverageNormal 头型绘制。
衣服按 Naked_Female 身体绘制。
两者都保留 512x512 画布中心和透明边距，不要裁切透明区域。
```
