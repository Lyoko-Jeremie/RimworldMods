# DoBill 资源测试

运行：`dotnet run --project ./Tests/DoBillResources/DoBillResources.csproj -c Release`。

项目无第三方包依赖，直接编译生产的数量预算、DoBill 预留账本、选料器和任务工具代码。
`GameDoubles.cs` 提供最小游戏对象与可注入拒收、部分接收、异常的容器；不会启动 RimWorld。

覆盖跨终端共享预算、营养混料、跨地图竞争、精确预留、重复队列、同类追加取料、多原料多趟搬运、
实际所有权回滚、提交回调重入、随身重复候选、活跃任务恢复、权限与清理。

这不是游戏内测试。实际 Harmony 补丁排序、其他 Mod 修改配方算法、寻路和存档解析，需要游戏内验证。

第二阶段首批增加普通搬运事务、运输数量服务和运输补丁的生产源码链接。
累计 38 项：新增生物塑形舱多槽多趟、总量任务不误接管、普通搬运 5 种交付结果、
跨任务预算保护、原版自身预留与重入、运输/交易预估、退休投影、大数饱和以及即时装载 5 种交付结果。

后续批次累计 49 项。新增生产总量协议与产品计数器：Reload/RefuelAtomic 多来源多趟、重复预留、
别名不足量、同 tick 定向失败保护、跨地图竞争、两种恢复位置、地面与随身来源混用、唯一锚点延迟兑现、
部分交付回队，以及产品计数去重、过滤、指定 slot、装备范围和快速 ResourceCounter 分支。
区域遍历补丁和最终 Wear/AddEquipment Harmony 绑定没有由这些替身测试模拟，仍需游戏内回归。
